Design rationale and component contract
Three-section navigation (Inbox, Work, Watch) Merges personal activity and pinned saved queries into Work while keeping Inbox for unread notifications and Watch for external changes.
Single query configuration Each saved query in Workspace can pin to Work and send new matches to Watch without copying query text into a separate monitor.
Unified 12 pt row layout Removes repository discovery cards and code-search monitors so every list shares one 18 pt Octicon state axis, two-line body, and 58 pt trailing action slot.
Single Workspace window and Apple Silicon target Combines watched targets and saved queries into one split window with inline delete confirmation, targeting arm64 on macOS 15+.
